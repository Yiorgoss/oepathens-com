## Overview

Multi-tenant, CMS-driven marketing-site platform (SvelteKit on Cloudflare Workers) rendering Payload CMS content, plus a client-side EPUB tool (Embolden). Vocabulary in `CONTEXT.md`; implementation map in `docs/architecture.md`.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `Yiorgoss/base-calisto`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
